# FoodSave AI — AI-SANA

**Save Food. Save Future.**

FoodSave AI — сұранысты болжау және азық-түлік қалдықтарын азайтуға арналған веб-платформа. Жоба AI-SANA бағдарламасы аясында төрт адамнан тұратын командамен 16 аптада MVP әзірлеуге бағытталған.

Платформа кафе, мейрамхана, асхана, наубайхана және азық-түлік дүкендеріне сатылым тарихы мен өнім қалдығына сүйеніп, қанша өнім дайындау немесе сатып алу керегін жоспарлауға көмектеседі.

## Командадағы 4 рөл

Қатысушылардың аты-жөндері мен GitHub логиндері кейін толтырылады. Төмендегі кесте жобадағы міндеттерді бөледі; GitHub аккаунттарына қолжетімділік әлі берілген жоқ.

| Қатысушы | Рөл | Жауапкершілік | MVP нәтижесі |
| --- | --- | --- | --- |
| 1 | Frontend Developer — интерфейс әзірлеушісі | UI/UX макеттері, React интерфейсі, Dashboard, өнімдер мен қалдықтарды енгізу формалары, графиктер, API-мен байланыс және жүктелу/қате күйлері | Телефон мен компьютерде жұмыс істейтін, сервер деректерін көрсететін интерфейс |
| 2 | Backend Developer — сервер әзірлеушісі | FastAPI, дерекқор құрылымы, өнім/сатылым/қалдық API-лары, деректерді тексеру, болжам сервисін қосу және серверді іске қосу | Құжатталған API, деректерді сақтау және интерфейс пен модельдің ортақ жұмысы |
| 3 | AI/ML Engineer — болжау моделінің әзірлеушісі | Датасетті дайындау, деректерді тазалау, қарапайым бастапқы болжам, Scikit-learn моделі, уақыт бойынша тексеру, MAE/WAPE бағалауы және дайындық көлемі бойынша ұсыныс | Қайта іске қосуға болатын болжам моделі және оның сапасын түсіндіретін есеп |
| 4 | Product & Marketing Manager — өнім және маркетинг менеджері | Клиент сұхбаттары, MVP талаптары, тапсырмалар мен 16 апталық жоспар, бизнес-модель, бәсекелестерді зерттеу, пилот кері байланысы, презентация және Demo Day | Расталған талаптар, басымдықтары анық тапсырмалар, бизнес-модель және финалдық таныстырылым |

### Бірлесіп жұмыс істеу

- Әр тапсырмада бір негізгі жауапты және тексерілетін нәтиже болады.
- Frontend және Backend әзірлеушілері API деректерінің форматын алдын ала келіседі.
- Backend және AI/ML әзірлеушілері модельге берілетін деректер мен болжам нәтижесінің форматын келіседі.
- Product Manager апта сайын орындалған жұмыс пен келесі апта басымдықтарын командамен нақтылайды.
- Әр қатысушы өз бөлігін тексереді; өзгерістерді біріктірер алдында басқа қатысушы қарап шығады.
- Пилот пен финалдық демонстрацияға төрт қатысушы да қатысады.

## MVP мүмкіндіктері

1. **Dashboard** — негізгі көрсеткіштер.
2. **Inventory Management** — өнімдер мен қалдықтарды есепке алу.
3. **Demand Forecasting** — алдағы күндерге сұраныс болжамы.
4. **AI Recommendations** — дайындау немесе сатып алу көлемі бойынша ұсыныстар.
5. **Waste Tracking** — есептен шығарылған өнімдерді тіркеу.
6. **Analytics** — сатылым, қалдық және есептелген үнем көрсеткіштері.

Алғашқы нұсқада тарихи деректерге негізделген болжам жасалады. Қалдықтың азаюы мен нақты үнем пилот нәтижелері арқылы бағаланады.

## Ұсынылған технологиялар

- Frontend: React + Vite
- Backend: Python + FastAPI
- AI/ML: Scikit-learn
- Дерекқор: PostgreSQL
