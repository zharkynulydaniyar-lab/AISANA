# FoodSave AI — AI-SANA

**Save Food. Save Future.**

FoodSave AI — сұранысты болжау және азық-түлік қалдықтарын азайтуға арналған веб-платформа. Жобаны төрт адам бірлесіп әзірлейді.

Платформа кафе, мейрамхана, асхана, наубайхана және азық-түлік дүкендеріне сатылым тарихы мен өнім қалдығына сүйеніп, қанша өнім дайындау немесе сатып алу керегін жоспарлауға көмектеседі.

## Төрт адамға міндеттерді бөлу

Қатысушылардың аты-жөндері мен GitHub логиндері кейін толтырылады. Бұл — жобадағы міндеттер бөлінісі; GitHub аккаунттарына қолжетімділік әлі берілген жоқ.

| Қатысушы | Рөл | Жасайтын бөлігі | Басқалармен байланысы |
| --- | --- | --- | --- |
| 1 | **Frontend Developer — дизайн және интерфейс** | Сайттың дизайны, Dashboard, өнім қосу, сатылым мен қалдық енгізу беттері, болжам мен ұсыныстарды көрсететін графиктер | 2-қатысушының API-ін интерфейске қосады; 3-қатысушының болжамын түсінікті көрсетеді; 4-қатысушымен қолдануға ыңғайлылығын тексереді |
| 2 | **Backend Developer — сервер және дерекқор** | Өнімдер, сатылымдар және қалдықтарды сақтау; деректерді тексеру; API; AI моделін серверге қосу; жүйені іске қосу | 1-қатысушыға деректерді беру мен сақтау API-ін дайындайды; 3-қатысушыға тарихи деректерді беріп, болжам нәтижесін қабылдайды; 4-қатысушымен қателерді тексереді |
| 3 | **AI/ML Engineer — деректер және болжам** | Датасетті дайындау, сұранысты болжау моделі, модель сапасын бағалау, қанша өнім дайындау немесе сатып алу керегіне ұсыныс | 2-қатысушымен модельдің кіріс және шығыс форматын келіседі; 1-қатысушыға болжам көрсеткіштерінің мағынасын түсіндіреді; 4-қатысушымен ұсыныстардың бизнеске пайдалы екенін бағалайды |
| 4 | **Product & QA Manager — өнім, тестілеу және таныстыру** | Пайдаланушы талаптары, қолдану сценарийлері, демонстрациялық деректер, толық жүйені тестілеу, қате есептері, клиент кері байланысы, бизнес-модель, маркетинг және презентация | Үш әзірлеушіге нақты талаптар мен қабылдау шарттарын береді; дайын функцияларды пайдаланушы ретінде тексереді; командамен бірге демонстрацияны дайындайды |

Әр қатысушы өз бөлігін іске асыруға жауапты. Талаптарды келісу, бөліктерді біріктіру, қателерді түзету және жобаны қорғау — бүкіл команданың ортақ жұмысы.

## Бір өнімге қалай бірігеді?

**Пайдаланушы дерек енгізеді → интерфейс серверге жібереді → сервер дерекқорға сақтайды → AI сұранысты болжайды → сервер нәтижені интерфейске береді → пайдаланушы график пен ұсынысты көреді.**

Мысалы, кафе нанның сатылымын және қалған санын енгізеді:

1. **1-қатысушы** дерек енгізу формасын және нәтиже бетін жасайды.
2. **2-қатысушы** енгізілген деректерді сақтап, болжамды есептеуге жібереді.
3. **3-қатысушы** тарихи деректерден келесі күннің сұранысын болжап, дайындау көлемін ұсынады.
4. **4-қатысушы** осы жолды басынан аяғына дейін тексереді: дерек дұрыс сақтала ма, болжам көрсетіле ме, ұсыныс пайдаланушыға түсінікті ме?

## Ортақ жұмыс тәртібі

- Әр функцияға бір жауапты белгіленеді, ал оған қажет басқа бөліктерді тиісті қатысушылар бірге жасайды.
- Frontend, Backend және AI әзірлеушілері деректер форматын алдын ала келіседі: өнім, күн, сатылым саны, қалдық және болжам.
- Әркім өзгерісін бөлек Git тармағында жасайды және Pull Request арқылы ұсынады. Басқа қатысушы қарап шыққаннан кейін өзгеріс негізгі тармаққа біріктіріледі.
- 4-қатысушы табылған қатені қайталау қадамдарымен және күтілетін нәтижемен бірге GitHub Issue ретінде жазады; тиісті әзірлеуші түзетеді.
- Функция интерфейсте жұмыс істеп, деректері сақталып, нәтижесі тексерілгенде дайын деп есептеледі.
- Толық демонстрацияны төрт адам бірге өткізеді және әрқайсысы өз бөлігін түсіндіреді.

## MVP мүмкіндіктері

1. **Dashboard** — негізгі көрсеткіштер.
2. **Inventory Management** — өнімдер мен қалдықтарды есепке алу.
3. **Demand Forecasting** — алдағы күндерге сұраныс болжамы.
4. **AI Recommendations** — дайындау немесе сатып алу көлемі бойынша ұсыныстар.
5. **Waste Tracking** — есептен шығарылған өнімдерді тіркеу.
6. **Analytics** — сатылым, қалдық және есептелген үнем көрсеткіштері.

Алғашқы нұсқада тарихи деректерге негізделген болжам жасалады. Қалдықтың азаюы мен нақты үнем пилот нәтижелері арқылы бағаланады.

## Ұсынылған технологиялар

- Frontend: React + Vite
- Backend: Python + FastAPI
- AI/ML: Scikit-learn
- Дерекқор: PostgreSQL
